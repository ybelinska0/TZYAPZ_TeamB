## Склад аркушів

| Аркуш | Що містить |
|---|---|
| **Беклог** | User stories US-01…US-nn за шаблоном «Як (роль), я хочу (…), щоб (…)»: ID, роль, бажання, мета, пріоритет, примітки для тестування, статус |
| **Очікування → stories** | Простежуваність: шість очікувань замовника (розділ 3.4 каталогу) і обмеження «оформлення не має стати складнішим» → історії, що їх покривають |


## Пріоритети

- **High** — без цього функція не має сенсу для замовника
- **Medium** — важливо, але можна відкласти на наступний реліз
- **Low** — доповнення

## Статуси

`чернетка` → `затверджено` після рецензії Скрам-майстра (відповідність шаблону) та Аудитора-опонента (покриття очікувань).
