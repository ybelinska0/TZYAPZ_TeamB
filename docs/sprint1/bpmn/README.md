# Моделі бізнес-процесів (BPMN 2.0)

Ця директорія містить вихідні файли діаграм бізнес-процесів для системи «ШопЛайн» (стан As-Is) та їх експортовані графічні копії.

## Інструментарій
Усі моделі розроблено в інструменті [diagrams.net](https://app.diagrams.net/) (Draw.io). 
Для редагування файлів `.drawio` рекомендується використовувати веб-версію або десктопний клієнт Draw.io, або відповідне розширення для VS Code.

## Перелік моделей

Команда виконала норматив (3 моделі) та додала одну додаткову для кращого покриття:

1. **Оформлення замовлення**
   * Вихідний файл: `01_order.drawio`
2. **Повернення товару**
   * Вихідний файл: `02_return.drawio`
3. **Обробка звернення з контактної форми**
   * Вихідний файл: `03_contact.drawio`
4. **Поповнення складу (додатково)**
   * Вихідний файл: `04_restock.drawio`

## Виконання нормативів моделювання
У розроблених діаграмах використано **4 типи шлюзів** (норматив \(\ge3\)):
* Шлюз на основі даних (Exclusive / XOR) — є в усіх моделях.
* Шлюз на основі подій (Event-based XOR) — використано в моделях 1, 2, 3.
* Паралельний шлюз (Parallel / ТА) — використано в моделі 1 (розгалуження та синхронізація).
* Інклюзивний шлюз (Inclusive / ОР) — використано в моделі 4 (робота з кількома постачальниками).

Протокол рецензування знаходиться у файлі [review.md](./review.md).
