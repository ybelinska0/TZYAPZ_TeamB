# BUG-013: Розділ «My invoices»: у таблиці рахунків немає колонки «статус» (F-130)

**Severity:** Minor   **Priority:** P3   **Status:** New
**Linked:** test case TC-021; requirement F-130

### Description
F-130 вимагає, щоб розділ «My invoices» показував список замовлень із колонками: номер, дата, сума, статус; TC-021 (крок 6) очікує цього. Фактично таблиця має колонки «Invoice Number», «Billing Address», «Invoice Date», «Total» і кнопку «Details»; колонки зі статусом замовлення немає, натомість є «Billing Address», який вимогою не передбачений.
Severity Minor: покупець не бачить статусу замовлення у списку, але номер, дата, сума і сторінка деталей доступні. Priority P3: на виконання інших кейсів дефект не впливає.

### Preconditions
Без входу в обліковий запис (нова сесія). Для входу використовується спільний запис demo: email `customer@practicesoftwaretesting.com`, пароль `welcome01`; у списку є рахунки з початкових даних demo.

### Steps to reproduce
1. Відкрити https://practicesoftwaretesting.com у Chrome (нова сесія) і натиснути «Sign in» у шапці.
2. У поле «Email address» ввести `customer@practicesoftwaretesting.com`, у поле «Password» — `welcome01`, натиснути «Login» — відкривається «My account».
3. Відкрити https://practicesoftwaretesting.com/account/invoices.
4. Переглянути заголовки колонок таблиці.

### Actual result
Після кроку 4: заголовки «Invoice Number», «Billing Address», «Invoice Date», «Total» і порожній заголовок колонки з кнопкою «Details»; колонки зі статусом немає.

### Expected result
Таблиця рахунків містить колонки: номер, дата, сума, статус (F-130).

### Environment
demo https://practicesoftwaretesting.com, 28.10.2026 (збірка v2.5 від 2026-10-11); Google Chrome 156.0.8078.73 (Official Build, 64-bit); Windows 11 25H2 (Build 26200.9711); розмір вікна не зафіксовано; обліковий запис customer@practicesoftwaretesting.com.
