# BUG-014: Реєстрація: повідомлення про помилку пароля виводиться під індикатором надійності, а не безпосередньо під полем «Password» (GUI-50)

**Severity:** Minor   **Priority:** P3   **Status:** New
**Linked:** test case TC-026; requirement GUI-50

### Description
GUI-50 вимагає, щоб повідомлення про помилку валідації поля виводилось текстом безпосередньо під відповідним полем. Фактично між полем «Password» і повідомленням стоять перелік правил пароля та індикатор надійності, а саме повідомлення розміщено в блоці над кнопкою «Register», далеко від поля. Для поля «First name» (TC-002) повідомлення стоїть безпосередньо під полем, тобто поведінка форми непослідовна. Примітка: розміщення повідомлення в SRS — пропозиція, що потребує підтвердження замовником; текст самого повідомлення — окремий звіт BUG-009.
Severity Minor: проблема інтерфейсу — помилку видно, але вона не поруч із полем, до якого належить. Priority P3: на виконання інших кейсів дефект не впливає.

### Preconditions
Без входу в обліковий запис (нова сесія); адреса teamb.p7.28101330@example.com не використовувалась для реєстрації.

1. Відкрити https://practicesoftwaretesting.com/auth/register у Chrome (нова сесія).
2. Ввести: First name «TeamB-Олена», Last name «Прикладова», Date of Birth «1995-05-15», Country «Ukraine», Postal code «01001», House number «10», Street «Тестова», City «Київ», State «Київська», Phone «0000000000», Email address «teamb.p7.28101330@example.com».
3. У поле «Password» ввести `Abcde1!` (7 символів: велика й мала літери, цифра, спецсимвол).
4. Натиснути кнопку «Register».
5. Переглянути, де на формі розташоване повідомлення про помилку пароля.

### Actual result
Після кроків 3–4: безпосередньо під полем «Password» — перелік правил пароля, нижче — індикатор надійності («Weak … Excellent»), і лише під ним, над кнопкою «Register», червоний блок із повідомленням про помилку.

### Expected result
Повідомлення про помилку пароля розташоване безпосередньо під полем «Password» (GUI-50).
