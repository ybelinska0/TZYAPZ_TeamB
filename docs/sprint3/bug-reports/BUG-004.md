# BUG-004: Меню на ширині 375 px: кнопка меню 56×40 px, а пункти «Home», «Contact», «Sign in» заввишки 40 px — менше за 44×44 px (U-30)

**Severity:** Minor   **Priority:** P3
**Linked:** test case TC-025; requirement U-30

### Description
U-30 вимагає, щоб за ширини вікна 375 px кнопки, придатні для натискання пальцем, були не менші за 44×44 px. Горизонтальної прокрутки немає і меню відкривається, але кнопка меню має розмір 56×40 px, а пункти «Home», «Contact», «Sign in» — 351×40 px («Categories» — 107.7×40 px): висота 40 px менша за 44 px. Перша картка товару (327×376 px) вимогу виконує.
Severity Minor: функціональність працює, проблема стосується зручності користування на сенсорному екрані. Priority P3: на виконання інших кейсів дефект не впливає.

### Preconditions
Без входу в обліковий запис.

### Steps to reproduce
1. Відкрити https://practicesoftwaretesting.com у Chrome (нова сесія).
2. Відкрити DevTools (F12), увімкнути Toggle device toolbar, у режимі Responsive встановити ширину 375 (висота 812).
3. Оновити сторінку (F5).
4. Натиснути кнопку меню навігації в шапці (три смужки).
5. Інструментом Inspect виміряти кнопку меню, пункти «Home», «Contact», «Sign in» і першу картку товару.

### Actual result
Після кроку 3: горизонтальної смуги прокрутки немає (ширина вмісту 375 px).
Після кроку 4: меню відкривається, пункти «Home», «Categories», «Contact», «Sign in», перемикач мови доступні.
Після кроку 5: кнопка меню — 56×40 px; «Home», «Contact», «Sign in» — по 351×40 px; «Categories» — 107.7×40 px; перша картка товару — 327×376 px.

### Expected result
Після кроку 5: кожен виміряний елемент не менший за 44×44 px (U-30); у цьому випадку кнопка меню і пункти меню мають бути заввишки щонайменше 44 px.

### Environment
demo https://practicesoftwaretesting.com, 27.10.2026 (збірка v2.5 від 2026-10-11); Chromium 152.0.7977.167 (вбудований браузер з емуляцією 375×812, мобільний пресет, Android user agent); Windows 10/11 (NT 10.0); без входу в обліковий запис. Розміри отримано через `getBoundingClientRect()`, що дає ті самі значення, що й Inspect у DevTools.
