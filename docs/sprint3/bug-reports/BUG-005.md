# BUG-005: Контактна форма відхиляє будь-який непорожній .txt («File should be empty.»), хоча F-140 допускає файл до 1 МБ

**Severity:** Normal   **Priority:** P3
**Linked:** test case TC-022; requirement F-140, GUI-90

### Description
F-140 допускає вкладення лише у вигляді файлу .txt розміром не більше 1 МБ. Форма з коректними полями і вкладенням `teamb-1kb.txt` (1024 байти, текст) не надсилається: під полем вкладення з'являється «File should be empty.», а підказка під полем стверджує «Only files with the txt extension are allowed, and files must be 0kb.». Фактично дозволено лише порожній файл, тож вкладення з вмістом додати неможливо. Це суперечить вимозі F-140 (межа 1 МБ — «пропоноване уточнення, потребує підтвердження замовником», тож рішення про фактичну межу потрібне від замовника).
Severity Normal: вкладення необов'язкове, звернення можна надіслати без файлу, але функція вкладення практично не працює. Priority P3: на виконання інших кейсів дефект не впливає.

### Preconditions
Без входу в обліковий запис. На комп'ютері виконавця є текстовий файл `teamb-1kb.txt` розміром 1024 байти (1 КБ).

### Steps to reproduce
1. Відкрити https://practicesoftwaretesting.com/contact у Chrome (нова сесія).
2. У поле «First name» ввести `TeamB-Анна`.
3. У поле «Last name» ввести `Тестова`.
4. У поле «Email address» ввести `teamb.anna@example.com`.
5. У списку «Subject» обрати `Customer service`.
6. У поле «Message» ввести `Доброго дня! Прошу уточнити деталі щодо гарантійного обслуговування товару.` (75 символів).
7. У полі «Attachment» натиснути «Choose File» і обрати `teamb-1kb.txt`.
8. Натиснути кнопку «Send».

### Actual result
Після кроку 7: у полі обрано `teamb-1kb.txt`; під полем підказка «Only files with the txt extension are allowed, and files must be 0kb.».
Після кроку 8: звернення не надіслано, форма лишається; під полем вкладення — повідомлення «File should be empty.»; повідомлення про прийняття звернення немає.

### Expected result
Після кроку 8: звернення надіслано, над формою — повідомлення про прийняття звернення (GUI-90, F-140: файл .txt до 1 МБ допустимий). Підказка під полем відповідає вимозі (.txt, до 1 МБ).

### Environment
demo https://practicesoftwaretesting.com, 28.10.2026 (збірка v2.5 від 2026-10-11); Chromium 152.0.7977.167 (вбудований браузер); Windows 10/11 (NT 10.0); вікно 1280×800; без входу в обліковий запис. Примітка щодо відтворення: у вбудованому браузері файл підставлено скриптом (File 1024 байти через DataTransfer), а не через вікно вибору файлу ОС; решту полів уведено з клавіатури. Аудитору слід виконати крок 7 вручну.
