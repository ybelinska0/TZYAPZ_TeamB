# BUG-012: Крок «Payment»: підсумок замовлення не містить вартості доставки (F-110, BL-60)

**Severity:** Normal   **Priority:** P3
**Linked:** test case TC-019; requirement F-110, BL-60

### Description
F-110 вимагає, щоб підсумок замовлення містив суму товарів і вартість доставки; за BL-60 доставка коштує 120,00, якщо сума після знижки менша за 1500,00. У TC-019 кошик містить один товар «Combination Pliers» (сума менша за 1500,00), тож у підсумку очікується рядок вартості доставки 120,00. Фактично на кроці «Payment» рядка вартості доставки немає. Примітка: SRS (F-110) залишає на підтвердження замовником застосування правила BL-60 до поточного інтерфейсу до інтеграції модуля знижок, але наявність рядка вартості доставки в підсумку вимагається незалежно від цього.
Severity Normal: замовлення оформити можна, але покупець не бачить вартості доставки до підтвердження. Priority P3: на виконання інших кейсів дефект не впливає.

### Preconditions
Кошик містить лише «Combination Pliers» у кількості 1 (додано в цій сесії); вхід не виконано; обліковий запис customer@practicesoftwaretesting.com (пароль — у кейсі TC-019).

### Steps to reproduce
1. Відкрити https://practicesoftwaretesting.com/checkout у Chrome (нова сесія) і натиснути «Proceed to checkout».
2. На кроці «Sign in» увійти обліковим записом customer@practicesoftwaretesting.com і натиснути «Proceed to checkout».
3. На кроці «Billing Address» ввести Street «TeamB-Тестова 10», City «Київ», State «Київська», Country «Ukraine», Postal code «01001» і натиснути «Proceed to checkout».
4. На кроці «Payment» переглянути підсумок замовлення.

### Actual result
Після кроку 4: підсумок замовлення без рядка вартості доставки.

### Expected result
Після кроку 4: підсумок містить суму товарів і вартість доставки 120,00 (сума товарів менша за 1500,00) — F-110, BL-60.

demo https://practicesoftwaretesting.com, 28.10.2026 (збірка v2.5 від 2026-10-11); Google Chrome 156.0.8078.73 (Official Build, 64-bit); Windows 11 25H2 (Build 26200.9711); розмір вікна не зафіксовано; обліковий запис customer@practicesoftwaretesting.com.
