# BUG-010: Відновлення пароля: після надсилання форми показується ключ перекладу «page.forgot-password.confirm» замість тексту повідомлення (F-30)

**Severity:** Normal   **Priority:** P3
**Linked:** test case TC-006; requirement F-30

### Description
F-30 вимагає після надсилання форми «Forgot Password» показати повідомлення про надсилання листа з посиланням. Фактично у зеленому блоці виводиться службовий ключ перекладу `page.forgot-password.confirm`, а не читабельний текст: користувач не може зрозуміти, що саме сталося. Повідомлення з'являється швидко (менше 60 с), тож вимога за часом виконується.
Severity Normal: функція доступна, але єдиний відгук системи на неї нечитабельний, і користувач не знає, чи лист надіслано. Priority P3: на виконання інших кейсів дефект не впливає.

### Preconditions
Без входу в обліковий запис (нова сесія). На demo є власний запис, зареєстрований через https://practicesoftwaretesting.com/auth/register із даними: First name `TeamB-Олена`, Last name `Прикладова`, Date of Birth `1995-05-15`, Country `Ukraine`, Postal code `01001`, House number `10`, Street `Тестова`, City `Київ`, State `Київська`, Phone `0000000000`, Email address `teamb.reset.28101330@example.com`, Password — будь-який, що проходить перевірку форми, наприклад `Fbcdf12!` (пароль `Abcde12!` форма відхиляє як такий, що трапився у витоку даних). Якщо адреса вже зайнята — змінити останню цифру в email (далі в кроках її теж).

### Steps to reproduce
1. Відкрити https://practicesoftwaretesting.com/auth/login у Chrome (нова сесія).
2. Натиснути посилання «Forgot your Password?».
3. У поле «Email address» ввести `teamb.reset.28101330@example.com`.
4. Натиснути кнопку «Set New Password» (кнопка надсилання під полем адреси).
5. Переглянути повідомлення під кнопкою.

### Actual result
Після кроку 4 менше ніж за 60 с під кнопкою з'являється зелений блок із текстом `page.forgot-password.confirm`.

### Expected result
Під кнопкою з'являється повідомлення читабельною мовою про те, що лист із посиланням для встановлення нового пароля надіслано (F-30).
