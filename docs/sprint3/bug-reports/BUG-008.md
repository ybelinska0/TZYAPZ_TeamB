# BUG-008: Форма реєстрації: обов'язкові поля позначено зірочкою непослідовно, біля поля «Password» зірочки немає (U-20, F-10)

**Severity:** Minor   **Priority:** P3
**Linked:** test case TC-002; requirement U-20, F-10

### Description
F-10 і U-20 вимагають, щоб обов'язкові поля форми реєстрації були позначені зірочкою; TC-002 (крок 1) очікує цього. Фактично зірочка в різних полях стоїть у різних місцях: у «First name» і «Last name» — лише в підказці всередині поля («First name *», «Your last name *»), а в мітці її немає; у «Date of Birth» — у мітці; у «Password» її немає ні в мітці, ні в підказці, хоча без пароля зареєструватися неможливо. Інші поля форми окремо не перевірялись.
Severity Minor: проблема інтерфейсу — реєстрація працює, але користувач не бачить, що пароль обов'язковий, а підказка із зірочкою зникає, щойно починається введення. Priority P3: на виконання інших кейсів дефект не впливає.

### Preconditions
Без входу в обліковий запис.

### Steps to reproduce
1. Відкрити https://practicesoftwaretesting.com/auth/register у Chrome (нова сесія).
2. Переглянути мітки й підказки полів «First name», «Last name» і «Date of Birth» у верхній частині форми.
3. Прокрутити форму до поля «Password» і переглянути його мітку та підказку.

### Actual result
Після кроку 2: мітки «First name» і «Last name» без зірочки (зірочка є лише в підказках «First name *» і «Your last name *»); мітка «Date of Birth *» із зірочкою, підказка «YYYY-MM-DD» без неї.
Після кроку 3: мітка «Password» і підказка «Your password» без зірочки.

### Expected result
Усі обов'язкові поля, зокрема «Password», позначено зірочкою однаково — у мітці поля (F-10, U-20).

### Environment
demo https://practicesoftwaretesting.com, 28.10.2026 (збірка v2.5 від 2026-10-11); Google Chrome 156.0.8078.73 (Official Build, 64-bit); Windows 11 25H2 (Build 26200.9711); розмір вікна не зафіксовано; без входу в обліковий запис.
