# BUG-008: Форма реєстрації: обов'язкові поля позначено зірочкою непослідовно, біля поля «Password» зірочки немає (U-20, F-10)

**Severity:** Minor   **Priority:** P3   **Status:** New
**Linked:** test case TC-002; requirement U-20, F-10

### Description
F-10 і U-20 вимагають, щоб обов'язкові поля форми реєстрації були позначені зірочкою; TC-002 (крок 1) очікує цього. Фактично зірочка стоїть у різних місцях: у мітці лише в одному з дванадцяти полів («Date of Birth *»); у решти полів, окрім пароля, — лише в підказці всередині поля (для списку «Country» — у першому пункті «Your country *»), і ця підказка зникає, щойно починається введення; біля «Password» зірочки немає ні в мітці, ні в підказці, хоча без пароля зареєструватися неможливо. Позначення полів по порядку наведено в Actual result.
Severity Minor: проблема інтерфейсу — реєстрація працює, але користувач не бачить, що пароль обов'язковий, а позначки обов'язковості нерівномірні. Priority P3: на виконання інших кейсів дефект не впливає.

### Preconditions
Без входу в обліковий запис.

### Steps to reproduce
1. Відкрити https://practicesoftwaretesting.com/auth/register у Chrome (нова сесія).
2. Зверху вниз переглянути мітку та підказку (текст усередині поля) кожного з дванадцяти полів форми.

### Actual result
Після кроку 2 (мітка → підказка або перший пункт списку):
- First name → «First name *» (у мітці зірочки немає);
- Last name → «Your last name *» (у мітці немає);
- Date of Birth * → «YYYY-MM-DD» (зірочка в мітці);
- Country → «Your country *» (перший пункт списку; у мітці немає);
- Postal code → «Your Postcode *» (у мітці немає);
- House number → «e.g. 42 *» (у мітці немає);
- Street → «Your Street *» (у мітці немає);
- City → «Your City *» (у мітці немає);
- State → «Your State *» (у мітці немає);
- Phone → «Your phone *» (у мітці немає);
- Email address → «Your email *» (у мітці немає);
- Password → «Your password» (зірочки немає ні в мітці, ні в підказці).

### Expected result
Усі обов'язкові поля, зокрема «Password», позначено зірочкою однаково — у мітці поля (F-10, U-20).
