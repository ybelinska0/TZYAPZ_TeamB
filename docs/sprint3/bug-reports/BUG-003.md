# BUG-003: Кількість 0 автоматично замінюється на 1, і товар додається в кошик без повідомлення про допустимий діапазон (GUI-30, BL-10)

**Severity:** Normal   **Priority:** P3
**Linked:** test case TC-015; requirement GUI-30, BL-10

### Description
GUI-30 вимагає, щоб значення поза межами 1..99 не приймалося; кейс TC-015 очікує, що товар не додається. Фактично поле саме змінює введене 0 на 1, кнопка «Add to cart» додає 1 одиницю і показує лише «Product added to shopping cart.»; повідомлення про допустимий діапазон 1..99 немає (для значення 100 воно є, див. BUG-002, — окремий звіт, бо реакція інтерфейсу інша).
Severity Normal: користувач, що ввів 0, мовчки отримує товар, який не збирався додавати, але кошик лишається в допустимому стані й видалити позицію можна. Priority P3: на виконання інших кейсів дефект не впливає.

### Preconditions
Без входу в обліковий запис; кошик порожній.

### Steps to reproduce
1. Відкрити https://practicesoftwaretesting.com у Chrome (нова сесія).
2. У поле пошуку ввести `Combination Pliers` і натиснути «Search».
3. Натиснути картку «Combination Pliers».
4. Виділити вміст поля «Quantity» (потрійний клік) і ввести `0`. Поле при повному очищенні саме підставляє 1, тому значення вводиться поверх виділеного.
5. Переглянути значення в полі «Quantity».
6. Натиснути кнопку «Add to cart».
7. Відкрити https://practicesoftwaretesting.com/checkout.

### Actual result
Після кроків 4–5: у полі «Quantity» значення 1, а не 0.
Після кроку 6: повідомлення «Product added to shopping cart.»; лічильник кошика = 1; повідомлення про допустимий діапазон немає.
Після кроку 7: у кошику 1 × «Combination Pliers».

### Expected result
Після кроків 4–6: значення 0 не прийнято; біля поля «Quantity» або поруч — повідомлення про допустимий діапазон 1..99; повідомлення про додавання немає; лічильник кошика не змінюється (GUI-30, BL-10).
Після кроку 7: кошик порожній, замість таблиці — текстове повідомлення (GUI-70).

### Environment
demo https://practicesoftwaretesting.com, 27.10.2026 (збірка v2.5 від 2026-10-11); Chromium 152.0.7977.167 (вбудований браузер); Windows 10/11 (NT 10.0); вікно 1280×800; без входу в обліковий запис.
