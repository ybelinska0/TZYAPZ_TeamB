# BUG-006: Кошик: повторне «Add to cart» дає в рядку 104 шт. — понад межу 99 (BL-20, F-100)

**Severity:** Major   **Priority:** P3
**Linked:** test case TC-031; requirement BL-20, F-100, F-90

### Description
BL-20 забороняє, щоб кількість у рядку після повторного додавання перевищувала 99; F-100 і BL-40 обмежують кількість у рядку діапазоном 1..99. Після додавання 99 шт. «Combination Pliers» і ще 5 шт. того самого товару кошик містить один рядок на 104 шт. із сумою $1,471.60. При цьому редагування кількості в рядку кошика межу тримає (введене 100 перетворюється на 99 з повідомленням «You can order at most 99 of this product.»), тобто обмеження існує, але не діє при повторному додаванні зі сторінки товару.
Severity Major: бізнес-правило межі кількості порушено і кошик містить недопустиму кількість, але замовлення в допустимих межах оформити можна. Priority P3: на виконання інших кейсів дефект не впливає.
Дефект знайдено дослідницькою перевіркою після завершення кейсів Run 1; кейс TC-031 за результатами цієї перевірки внесено до test-cases.xlsx (Бобров П., 28.10.2026) і прорецензовано (Кочаров Д., 28.10.2026).

### Preconditions
Без входу в обліковий запис; кошик порожній (нова сесія).

### Steps to reproduce
1. Відкрити https://practicesoftwaretesting.com у Chrome (нова сесія).
2. У поле пошуку ввести `Combination Pliers`, натиснути «Search», натиснути картку «Combination Pliers».
3. Виділити вміст поля «Quantity» (потрійний клік), ввести `99`, натиснути «Add to cart».
4. Виділити вміст поля «Quantity», ввести `5`, натиснути «Add to cart».
5. Відкрити https://practicesoftwaretesting.com/checkout.

### Actual result
Після кроку 3: повідомлення «Product added to shopping cart.», лічильник кошика = 99.
Після кроку 4: повідомлення «Product added to shopping cart.», лічильник кошика = 104; повідомлення про межу немає.
Після кроку 5: один рядок «Combination Pliers», Quantity 104, ціна $14.15, Total $1,471.60 (104 × 14.15).

### Expected result
Після кроку 4: сумарна кількість не перевищує 99 — додавання відхилено з повідомленням про межу (лічильник лишається 99) або кількість обмежена 99 (BL-20).
Після кроку 5: у кошику рядок «Combination Pliers» із кількістю не більше 99 (F-100, BL-40).
