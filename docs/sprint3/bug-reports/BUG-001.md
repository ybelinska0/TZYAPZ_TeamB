# BUG-001: Пошук 'hammer' не знаходить «Sledgehammer»: збіг шукається не за підрядком (F-60)

**Severity:** Major   **Priority:** P3   **Status:** New
**Linked:** test case TC-010; requirement F-60

### Description
F-60 вимагає знаходити товари, назва яких містить запит як підрядок без урахування регістру. Запит `hammer` повертає 6 товарів і пропускає «Sledgehammer», хоча його назва містить 'hammer'; запит `ham` повертає 7 товарів, серед них «Sledgehammer»; запит `mmer` не повертає жодного товару, хоча 'mmer' є підрядком у «Hammer», «Claw Hammer» та інших назвах. Отже, покупець не знаходить наявний товар за частиною назви.
Severity Major: пошук (F-60, пріоритет High) працює не повністю — результати неповні, але товар можна знайти коротшим запитом або через каталог. Priority P3: на виконання інших кейсів дефект не впливає.

### Preconditions
Без входу в обліковий запис; кошик порожній.

### Steps to reproduce
1. Відкрити https://practicesoftwaretesting.com у Chrome (нова сесія).
2. У поле пошуку ввести `hammer`.
3. Натиснути кнопку «Search».
4. Переглянути підпис над результатами і всі картки.
5. Натиснути кнопку «X», у поле пошуку ввести `ham`, натиснути «Search».
6. Натиснути кнопку «X», у поле пошуку ввести `mmer`, натиснути «Search».

### Actual result
Після кроку 3: заголовок «Searched for: hammer», підпис «6 products found for 'hammer'»: Claw Hammer with Shock Reduction Grip, Hammer, Claw Hammer, Thor Hammer, Claw Hammer with Fiberglass Handle, Court Hammer. Товару «Sledgehammer» немає в результатах.
Після кроку 5: «7 products found for 'ham'», серед них «Sledgehammer».
Після кроку 6: жодного товару.

### Expected result
Після кроку 3: усі товари, у назві яких є 'hammer' у будь-якому регістрі, — 7 карток, включно з «Sledgehammer» (F-60).
Після кроку 6: ті самі 7 товарів, бо 'mmer' є підрядком кожної з цих назв (F-60).
