# BUG-007: Шапка: логотип «TOOLSHOP» замість «ШопЛайн» (GUI-10)

**Severity:** Trivial   **Priority:** P3   **Status:** New
**Linked:** test case TC-004; requirement GUI-10

### Description
GUI-10 вимагає, щоб шапка кожної сторінки містила логотип «ШопЛайн» (посилання на головну сторінку). На demo в шапці стоїть логотип «TOOLSHOP» з позначкою «DEMO»; напису «ШопЛайн» немає ні на головній, ні на сторінках «Contact», товару і кошика. Еталон — SRS: продукт П1 називається «ШопЛайн», а «Toolshop» — лише назва навчального demo.
Severity Trivial: косметична розбіжність брендингу, функціональність не страждає. Priority P3: на виконання інших кейсів дефект не впливає.
Рішення команди (28.10.2026): невідповідність логотипу вважаємо дефектом, еталон — SRS (GUI-10); стан Rejected не застосовується.

### Preconditions
Без входу в обліковий запис.

### Steps to reproduce
1. Відкрити https://practicesoftwaretesting.com у Chrome (нова сесія).
2. Переглянути логотип у лівій частині шапки.
3. Відкрити https://practicesoftwaretesting.com/contact і переглянути шапку.

### Actual result
Після кроку 2: у шапці логотип із написом «TOOLSHOP» і позначкою «DEMO»; напису «ШопЛайн» немає.
Після кроку 3: шапка така сама — логотип «TOOLSHOP».

### Expected result
Після кроків 2–3: шапка містить логотип «ШопЛайн» (посилання на головну сторінку) (GUI-10; TC-004, крок 1).

### Environment
demo https://practicesoftwaretesting.com, 27.10.2026 і 28.10.2026 (збірка v2.5 від 2026-10-11); Chromium 152.0.7977.167 (вбудований браузер); Windows 10/11 (NT 10.0); вікно 1280×800; без входу в обліковий запис.
