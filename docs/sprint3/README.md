## 1. Мета спринта

Розробити незалежні тест-кейси на основі виправленої специфікації SRS v1.1, виконати тестування demo-застосунку «ШопЛайн» (https://practicesoftwaretesting.com), задокументувати виявлені дефекти у GitHub Issues / файлах звітів та провести внутрішнє рецензування артефактів.

Інкремент спринта: **Досьє тестування v3** — набір з 31 незалежного тест-кейсу, журнал виконання (31 прогін), реєстр з 14 дефектів, матриця покриття вимог та звіт аудитора.

## 5. Покриття вимог специфікації SRS v1.1

Усі 41 вимога специфікації проаналізовані та внесені до матриці покриття (`Coverage`):

### 5.1. Повністю покриті вимоги (23 вимоги)
`F-10`, `F-20`, `F-30`, `F-40`, `F-50`, `F-60`, `F-70`, `F-80`, `F-90`, `F-100`, `F-110`, `F-120`, `F-140`, `GUI-10`, `GUI-20`, `GUI-30`, `GUI-40`, `GUI-50`, `GUI-60`, `GUI-65`, `GUI-70`, `GUI-90`, `U-30`.

### 5.2. Частково покриті вимоги (8 вимог)
- **`F-130`**: Перевірено розділи «My invoices» (TC-021) та «My favorites» (TC-020). Розділи «My profile» та «My messages» не змінювалися задля уникнення модифікації даних спільних записів demo (п. 5.4 методички).
- **`BL-10`, `BL-20`, `BL-40`, `BL-60`**: Інтерфейсні межі (кількість 1..99, додавання в кошик, вартість доставки) покриті кейсами TC-014..TC-017, TC-019, TC-030, TC-031. Логіка класів C++ та винятки перевіряються unit-тестами у Спринті 4.
- **`S-10`, `S-20`, `U-20`**: Покриті перевірочними кейсами TC-002, TC-024, TC-029 шляхом спостереження без порушення правил безпеки публічного demo.

### 5.3. Обґрунтовано не покрито у Спринті 3 (10 вимог)
- **`BL-50`, `BL-70`, `BL-80`**: Модулі бізнес-логіки (знижки, промокоди) не інтегровані в UI (SRS, 2.3) — покриваються unit-тестами у Спринті 4.
- **`GUI-80`, `GUI-100`, `P-10`**: Вимоги мають статус пропозицій (потребують підтвердження замовником) — перевірка через DevTools у Спринті 5.
- **`P-20`**: Навантажувальне тестування заборонене на публічному demo (п. 5.4 методички) — виконується на локальному резерві.
- **`U-10`**: Формат юзабіліті-дослідження на 5 учасниках, а не функціональний тест-кейс.
- **`D-10`, `D-20`**: Перевірка посібника користувача та README модулів перенесені до Спринту 4.
