# Запропонований тест-кейс TC-031 (для додавання до test-cases.xlsx)

Кейс виник із дослідницької перевірки: дефект BUG-006 не відповідає жодному з кейсів TC-001…TC-030 (повторне додавання з перевищенням 99 не перевіряється). За методикою кожен звіт має бути прив'язаний до кейсу, тому нижче — кейс у форматі аркуша «Test cases». Перед використанням його має прорецензувати колега за 8-пунктним чеклістом (аркуш «Review»), а в аркуші «Coverage» потрібно оновити покриття BL-20 і F-100.

| Поле | Значення |
| --- | --- |
| TC-ID | TC-031 |
| ID вимоги | BL-20, F-90, F-100 |
| Заголовок | Повторне додавання того самого товару не збільшує кількість у рядку кошика понад 99 |
| Передумови | Chrome 120+, нова сесія (інкогніто), вікно 1280×800; вхід не виконано. Кошик порожній. Граничне значення: після повторного додавання сумарна кількість 99 + 5 = 104 перевищує межу 99. |
| Кроки | 1. Відкрити https://practicesoftwaretesting.com.<br>2. У поле пошуку ввести 'Combination Pliers'.<br>3. Натиснути кнопку «Search».<br>4. Натиснути картку «Combination Pliers».<br>5. Виділити вміст поля «Quantity» і ввести '99'.<br>6. Натиснути кнопку «Add to cart».<br>7. Виділити вміст поля «Quantity» і ввести '5'.<br>8. Натиснути кнопку «Add to cart».<br>9. Відкрити https://practicesoftwaretesting.com/checkout.<br>10. Закрити вкладку. |
| Очікуваний результат | 1–4. Відкривається сторінка товару «Combination Pliers» (адреса /product/…).<br>5–6. Товар додано: лічильник кошика в шапці = 99.<br>7–8. Сумарна кількість не перевищує 99: додавання відхилено з повідомленням про межу або кількість обмежена 99; лічильник кошика не більший за 99 (BL-20, F-90).<br>9. У кошику один рядок «Combination Pliers» із кількістю не більше 99 (BL-20, F-100). |

Зауваження до кроків 5 і 7 у вже наявних кейсах TC-014, TC-015, TC-030: кроки «Очистити поле «Quantity» і ввести …» на demo дають хибне значення, бо порожнє поле саме підставляє 1 (результат «очистити + 0» — «10», «очистити + 100» — «1100»). У цьому кейсі, як і під час виконання Run 1, значення вводиться поверх виділеного вмісту поля.
