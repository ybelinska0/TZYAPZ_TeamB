# UI-сценарії автотестів «ШопЛайн» (Sprint 4 — TTS-60)

**Демо-застосунок для UI-тестів:** резервний Sauce Demo (`https://www.saucedemo.com/`, `standard_user` / `secret_sauce`).
**Підстава:** рішення викладача про перехід на резервний demo, погоджене в робочому чаті дисципліни (док. 06 §1.3).
**Чому не Toolshop:** публічний стенд `practicesoftwaretesting.com` блокує автоматизовані прогони WebDriver через захист Cloudflare/капчу та нестабільність мережевого доступу.

Кожен UI-тест відповідає тест-кейсу спринта 3 з тим самим TC-ID (`docs/sprint3/test-cases.xlsx`, аркуш «Test cases»). Кейси спринта 3 написано для Toolshop, тому для резервного demo кожен перенесено так:
- **Перенесено:** перевірки, які мають відповідник у Sauce Demo (та сама вимога, той самий тип перевірки).
- **Не перенесено:** елементи, яких у Sauce Demo немає. Вони лишаються ручними перевірками кейсу спринта 3 на Toolshop і будуть автоматизовані, щойно команда повернеться на основний demo.
